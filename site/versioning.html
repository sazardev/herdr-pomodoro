Versioning.

Semantic versioning, the release process, and the full release history for herdr-pomodoro.

01Semantic versioning

herdr-pomodoro follows Semantic Versioning: MAJOR.MINOR.PATCH, where MAJOR is a breaking config/manifest/CLI change, MINOR is a backwards-compatible feature, and PATCH is a fix or polish pass.

Cargo.toml's [package] version is the single source of truth; the binary reads it back at compile time (herdr-pomodoro --version), and herdr-plugin.toml's version is kept in lockstep with it.

02Cutting a release

1

As you make changes, add bullets under ## [Unreleased] in CHANGELOG.md (grouped as ### Added / ### Changed / ### Fixed etc., per Keep a Changelog).

2

Run the bump script. It bumps both TOML files, promotes [Unreleased] into a dated [X.Y.Z] section, refreshes Cargo.lock, and -- inside a git repo -- commits and tags vX.Y.Z.

scripts/bump-version <major|minor|patch|X.Y.Z>
scripts/bump-version minor --dry-run   # preview only
scripts/bump-version patch --no-git    # skip commit/tag
3

Push the commit and the tag:

git push && git push origin vX.Y.Z

Full history in CHANGELOG.md, tagged releases on GitHub Releases.

03Release history

0.2.0 -- 2026-09-08
  • Analog progress ring with rim ticks and a position marker
  • Toasts (started / paused / resumed / phase-complete) in every mood
  • First-run setup wizard with a live preview per view
  • Work-session history with a rolling stats overlay
  • Fixed: digital/flashy no longer clip in short panes
  • Fixed: minimal no longer truncates status in narrow panes
  • Fixed: main pane now declares placement = "split" explicitly instead of relying on Herdr's implicit overlay default
0.1.0 -- 2026-09-08
  • Four static, text-only moods with auto-downgrade for small panes
  • Classic / deep-work / quick presets, plus custom presets
  • Theme-adaptive rendering via the standard ANSI palette
  • Global shortcuts and one-shot subcommands
  • Desktop notifications and terminal bell on phase completion
  • No-daemon design: timer truth is a wall-clock end-timestamp
